# 75-second demo script

**0–10 seconds — the problem**

Open the deployed AgentProfiles homepage in ChatGPT Desktop’s built-in browser. Say: “Business profiles made the web easier for people to understand. AgentProfiles is a first look at a profile-aware web for agents.” Enter the demo.

**10–20 seconds — discoverability**

Open the site-tools control in the browser address bar. Show `find_businesses`, `check_availability`, and `book_appointment`, including the booking tool’s confirmation-focused description.

**20–50 seconds — shared concierge flow**

Ask for an appointment in the seeded city and give a neighbourhood preference. Show the agent comparing the returned location, pricing, and availability evidence. Then ask for a specialty that only one profile documents, so the agent can explain why service fit can outweigh distance.

**50–70 seconds — trusted commitment**

Confirm the selected slot. Show the booking confirmation card, then refresh/re-open availability to prove the slot is gone. State that Supabase claims the slot and creates the appointment atomically, so it cannot be double-booked.

**70–75 seconds — closing**

“AgentProfiles shows what the web feels like when people choose the context their agents can use, then work with trusted services through transparent, confirmable actions.”
