# 75-second demo script

**0–10 seconds — the problem**

Open the deployed AgentProfiles homepage in ChatGPT Desktop’s built-in browser. Say: “Business profiles made the web easier for people to understand. AgentProfiles is a first look at a profile-aware web for agents. DentalBookings is our first proof.” Point out the green **WebMCP active** badge.

**10–20 seconds — discoverability**

Open the site-tools control in the browser address bar. Show `find_clinics`, `check_availability`, and `book_appointment`, including the booking tool’s confirmation-focused description.

**20–50 seconds — shared concierge flow**

Ask: “Book my usual dentist next week, preferably after 14:00. Compare alternatives before I confirm.” Show the agent activity panel updating with the selected preference context, clinic search, and availability comparison. Explain that the agent gets decision-ready clinic, dentist, and local-time data, not a scraped interface.

**50–70 seconds — trusted commitment**

Confirm the selected slot. Show the booking confirmation card, the agent activity event, and refresh/re-open availability to prove the slot is gone. State that Supabase claims the slot and creates the appointment atomically, so it cannot be double-booked.

**70–75 seconds — closing**

“AgentProfiles shows what the web feels like when people choose the context their agents can use, then work with trusted services through transparent, confirmable actions.”
